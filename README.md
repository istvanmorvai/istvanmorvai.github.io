# István Morvai — Professional website

A responsive one-page professional website. Static HTML and CSS, hosted with GitHub Pages. No build step, forms, analytics or application backend.

## Editing

Edit `index.html` for content and `style.css` for appearance. GitHub Pages publishes the root of the `main` branch. `favicon.svg` supplies the browser icon; `.nojekyll` keeps publication static.

## Preview locally

Run `python3 -m http.server 8080` in this directory, then open `http://localhost:8080`.

## Content sources

- LinkedIn profile identified through the connected LinkedIn search and confirmed by István: https://www.linkedin.com/in/istvanmorvai/
- Professional experience and project details: https://www.neox.team/about (accessed 23 October 2026).
- Public contact email provided by István.

LinkedIn experience was verified in the user’s signed-in Safari session. The public NEOX biography supplies the experience totals and additional project context. No client results, certifications or testimonials have been invented.

## Hosting

Publish from `main` / `/ (root)` in repository Settings → Pages. The public URL is https://istvanmorvai.github.io/ . GitHub Pages supports free hosting from public repositories. A third-party signup service determines independently whether it accepts a given website.

Typography uses Google Fonts with local system font fallbacks. The site itself sets no cookies and has no tracking scripts; hosting and font providers have their own request logging policies.
